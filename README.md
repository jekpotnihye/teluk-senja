Teluk Senja is an original open-world crime game set in a sun-soaked coastal city at dusk, rendered in GTA III-style low-poly 3D with a hand-written raw WebGL renderer (shaders and procedural geometry written from scratch, no libraries) and a Canvas 2D HUD overlay, plus WebAudio — no network, no external assets. Play Raka, a driver for the Teluk Senja harbour crew, across 8 story missions: deliveries, a car theft, a warehouse shootout, an escape chase, a street race, and a final showdown with the smuggling king. Drive through five districts (Pelabuhan Senja, Pasar Ikan, Kota Tua, Bukit Kaca, Dermaga Lama) with traffic, pedestrians, a live minimap, a wanted system with PTS police pursuit, roadblocks and a searchlight helicopter, a crew system (Sinta as getaway driver, Bang Dodi as fence and mechanic), a garage with upgrades, weapon slots, radio stations, a dusk-to-night shift with headlights and a lighthouse beam, and saves in localStorage.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
